# What-Movie-should-i-Watch-
Built with Python &amp; Tkinter, this app pulls live movie data from the IMDB API, writes the data into separate JSON files, analyzes your personal taste through a built-in quiz, pulls live film data from the IMDB API, and cross-references it against your preferences, and tells you what movie you should be watching.
